# 관리자 입력 구조 v2

- 지점명은 장소명에 합치며 동일한 접미사를 중복 추가하지 않는다. 읍/면/동은 입력·고객 지역 표기·필터 기준에서 제외한다. 전체 주소와 시/도, 시/군/구를 사용한다.
- 예약 필드는 기본 정보, 주차 필드는 가격으로 이동한다.
- 테마 입력은 감도·체력빼기·경험희소성 및 평가 근거, 수유실·기저귀갈이대로 구성한다.
- 공개 카드는 한줄 소개, 연령 힌트, 주의사항이다. A/B 카드 모두 표시한다. 추천 이유·수동 추천 점수·티켓 후보·제휴 링크·검수자 입력은 제거한다. 과거 열은 복구용으로 보존하며 신규 추천은 태그 점수를 사용한다.
- prices JSON의 각 연령 행에 weekdayPrice/weekendPrice를 저장한다. 0=무료, 빈 문자열=미확인. 토·일은 주말, 월~금은 평일. 공휴일 예외와 할인·유효기간은 note에 보존해 노출한다.
- 기존 명시적 평일/주말 문장을 분리한다. 확인된 무료는 양쪽 0, 미확인은 양쪽 빈 값, 요일 구분 없는 과거 요금은 기존 공통요금으로 보존한다. 임의 요금 추정은 하지 않는다.
- 관리자 최초 로딩에서 인증된 upgrade-format을 호출한다. ID/name/branch/prices만 서버에서 읽고 50행씩 처리한다. 원본 일치 조건으로 갱신해 동시 수정 충돌을 방지하며 반복 실행은 변경 0건이다. 공개·검토 상태와 기타 내용은 변경하지 않는다.
- 대표 이미지는 인증된 관리자만 JPG/PNG/WebP 5MB까지 업로드한다. 실제 파일 시그니처 검증 후 R2 PLACE_IMAGES에 저장하며 DB에는 내부 경로를 저장한다. 이미지 출처 URL은 별도 보존한다. 기존 이미지 URL이 있으면 그대로 유지한다.
